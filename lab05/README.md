# Лабораторна робота №5. Ліниві обчислення з генераторами та itertools

Варіант 13

## Мета роботи

Реалізувати ліниву обробку числового потоку й обчислювати максимум,
мінімум і розмах у ковзних вікнах.

## Опис програми

У `streams.py` функція `drop` пропускає початкові спостереження,
`sliding_window` генерує кортежі з буфера `deque(maxlen=k)`,
`starmap` обчислює `(max, min, max - min)`, а `take` зупиняє
конвеєр після перших N результатів. `count` є нескінченним джерелом,
`islice` обмежує споживання, а `accumulate` обчислює префіксні суми.
Окремі приклади демонструють `fib_stream` і `moving_average`.

Для потоку `(4, 1, 7, 2, 6, 3)`, k=3 і N=3 програма
повертає `((7, 1, 6), (7, 1, 6), (7, 2, 5))`.
Для N=0 джерело не споживається. Порожній потік і потік довжини
меншої за k дають порожню відповідь. Для k≤0 або від’ємних N і skip
виникає `ValueError`. Для N>0 і достатнього потоку конвеєр читає
skip + k + N − 1 елементів. Буфер потребує O(k) пам'яті,
а кортеж із результатами — O(N).

## Встановлення

Потрібен Python 3.10 або новіший. Відкрийте термінал у каталозі цієї лабораторної та виконайте:

```text
python -m venv .venv
```

Активуйте середовище командою `.venv\Scripts\activate` у Windows CMD,
`.\.venv\Scripts\Activate.ps1` у PowerShell або `source .venv/bin/activate`
у Linux/macOS, далі встановіть залежності:

```text
python -m pip install -r requirements.txt
```
